Description JSON (schémas)

  • capsules.json : id, title, macro, summary, objectif, level, content, redflags[], tags[], media[].
  • notions.json : id, title, domain, summary, content, tags[].
  • questions.json : q, options[4], answer(0-3), explain, domain.
  • diagnostic.json : q, options, answer (optionnel), domain.

Process d'ajout de contenu

  1. Ajouter l'élément JSON dans le fichier concerné.
  2. Renseigner au minimum les champs titre, résumé, domaine/macro et contenu.
  3. Associer un média local si pertinent via assets/media/**.
  4. Vérifier l'affichage avec recherche + overlay + correction/calcul.
