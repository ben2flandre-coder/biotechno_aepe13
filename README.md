# Biotechnologie — CAP AEPE (Phase 1)

Plateforme statique orientée animation adulte/pro en CAP AEPE Bloc 1 / EP3.

## Cadre appliqué
Phase 1 uniquement, sans banque QCM massive et sans diagnostic actif.

## Exigence pédagogique réalisée
Chaque séquence est conçue comme un support d’animation de 2 à 3 heures avec structure obligatoire :
1. Situation réelle d’ouverture (EAJE)
2. Problème métier (erreur fréquente)
3. Analyse technique
4. Apport théorique relié terrain
5. Micro-protocole numéroté
6. Tableau erreur → risque → conséquence → prévention
7. Non-conformité type EP3
8. Point vigilance inspectable
9. Mémo imprimable

Et chaque séquence contient :
- 2 situations concrètes
- 1 arbitrage décisionnel
- 1 cas pratique groupe
- 1 piège d’examen
